# pxd-team-pulse — 팀 구성 스냅샷 분석

지금 이 순간의 pxd 팀 온보딩 응답 전체를 aggregate 해서, 팀의 구성 · 취향 · 다양성을 한눈에 보여주는 스냅샷 리포트를 만든다.

## 언제 발동

사용자가 다음을 언급:
- "팀 구성", "팀 분포", "팀 통계"
- "team pulse", "team pulse 뽑아줘"
- "온보딩 데이터 분석", "응답 요약"

## 데이터 소스

Vercel API 에서 전체 응답 GET:

```bash
curl -sS https://pxd-api.vercel.app/api/responses
```

응답 형식: `{ "count": N, "responses": [ {name, age, hobby, food, movie, mbti, submitted_at}, ... ] }`

## 절차

### 1. 데이터 fetch

curl 로 API 호출. 실패하면 "⚠ API 응답 실패" 알리고 종료.

### 2. 기본 통계

- **총 응답 수**: N 명
- **가장 최근 응답 시각**: 마지막 `submitted_at`
- **응답 완결성**: 6개 필드 다 채운 응답 비율 (%)

### 3. 다섯 축 분포 집계

각 축별로 아래 형식의 세로 막대 (ASCII) 로 표시:

**나이 분포** (10년 버킷):
```
20-29:  ████████ 5명 (25%)
30-39:  ████████████████ 10명 (50%)
40-49:  ██████ 4명 (20%)
50+:    ██ 1명 (5%)
```

**MBTI 분포** (16타입, 실제 나온 것만 표시):
```
ENFP:   ████ 3명
INTJ:   ███ 2명
ENTJ:   ██ 1명
...
```

+ **4축 요약**: E/I, S/N, T/F, J/P 비율 (예: E 60% · I 40%)

**취미 · 음식 · 영화 카테고리** (LLM 판단으로 카테고리 부여):
- 취미: outdoor / creative / consumption / social / etc
- 음식: 한식 / 양식 / 일식 / 중식 / 기타
- 영화: SF / 로맨스 / 액션 / 드라마 / 코미디 / 기타

각각 세로 막대로.

### 4. 다양성 인사이트 (2~3문장)

수치를 보고 팀의 특성 한 줄로 요약. 예:
- "이 팀은 30대 · N성향 · 다양한 취향의 매트릭스형 조직."
- "MBTI 는 편중돼있지만 취미와 음식은 매우 분산 — 사고 스타일은 유사하나 라이프스타일은 각자."

### 5. 결과물

Chat 에 위 리포트를 그대로 표시 (파일 저장은 옵션).

파일 저장이 필요한 경우: 현재 작업 디렉토리에 `team_pulse_YYYYMMDD.md` 로 저장.

## 리포트 형식 예시

```
📊 pxd 팀 구성 스냅샷
=======================

총 응답: 4명 · 최근 제출: 2026-08-03 22:53
응답 완결성: 3/4 명 (75%)

── 나이 분포 ──
20-29:  ████████ 2명
30-39:  ████████████ 3명
40+:    (없음)

── MBTI 분포 ──
ENTJ:   ████ 1명
INFP:   ████ 1명
ENTP:   ████ 1명
TEST:   ████ 1명   ← (테스트 데이터로 보임)

축 요약: E 75% · N 100% · T 25% · P 50%

── 좋아하는 음식 카테고리 ──
한식:   ████ 1명 (냉면)
일식:   ████ 1명 (돈까스)
기타:   ████ 1명 (검증)
(미기입: 1명)

── 취미 분포 ──
게임:      ████ 1명
캠핑:      ████ 1명
영화시청:  ████ 1명
검증:      ████ 1명

── 다양성 인사이트 ──
N성향(직관형)이 압도적. 취향은 매우 분산되어 있어 개별 
프로젝트에서 다양한 관점이 나올 조합. MBTI E/I 는 편중돼 
있으니 회의 진행 시 조용한 I 성향 배려 필요.
```

## 특이 케이스

- **응답 0개**: "아직 온보딩 응답이 없습니다. `/pxd` 로 응답부터 수집하세요."
- **응답 3명 미만**: "표본이 작아 분포 해석에 주의" 경고 문구 상단에 표시.
- **테스트 데이터 감지** (MBTI 가 TEST 나 XXXX 등 비정상): 해당 항목에 `← 테스트 데이터로 보임` 표시.
- **API 실패**: 에러 그대로 보여주고 종료. 로컬 백업 폴더 (`~/pxd-responses/*.md`) 있으면 그것으로 fallback 옵션 안내.

## 관련 스킬

- `pxd-6frame` — 인터뷰 트랜스크립트 태깅 (다른 데이터 소스)
- `pxd-lunch` (커맨드) — 음식 데이터만 조회 (더 좁은 범위)

pxd-team-pulse 는 **집계형 분석** 의 예시. pxd-6frame 은 **매핑형 분석** 의 예시. 팀은 필요한 분석 유형에 따라 새 스킬을 만들어 이 라이브러리를 확장.
