# pxd-story — 보고서를 소설처럼 다시 쓰기

리서치 보고서를 문학적으로 재구성한 **오프닝 콜아웃 박스** 를 원본 최상단에 붙인 복제본을 만든다. 클라이언트 미팅 오프닝, 사내 공유용 티저, 리포트 요약 프리뷰 등에 활용.

## 입력

`$ARGUMENTS` — 대상 보고서 파일:
- 상대경로 (`report.md`) 또는 절대경로 (`/Users/.../final_report.md`)
- 확장자: `.md` 우선, `.html`/`.txt` 도 처리 (html 은 태그 제거 후 텍스트만)

## 실행 절차

### 1. 파일 존재 확인

파일이 없으면 안내하고 종료:
- 상대경로면 현재 작업 디렉토리 기준으로 먼저 찾음
- 그래도 없으면 "파일을 찾을 수 없습니다: `<입력값>`" 표시

### 2. 원본 읽기 · 분석

파일 전체를 읽고 다음을 파악:
- **연구 대상 · 배경** (도입부에서)
- **핵심 발견 3~5개** (본문에서)
- **인상적 인용문 1~2개** (있다면)
- **최종 결론 · 시사점**

너무 긴 보고서(10만자+)면 요약 대상은 목차 + 각 섹션 첫 문단 + 결론에 국한.

### 3. 소설풍 재구성 (콜아웃 본문 생성)

**작성 원칙**:
- **3~5문단**, 각 문단 3~5문장
- **관찰자 시점 또는 참여자 시점** — "그녀는 매장 앞에서 잠시 멈춰 섰다" 같은 서사
- **현재형 · 과거형 자유롭게**, 문학적 리듬 우선
- **참여자를 익명 등장인물화** ("30대 워킹맘 A", "3년차 소비자 P4" 등)
- **팩트는 절대 왜곡 금지** — 발견 사항의 실체는 유지하되 표현만 서사화
- **결말 열어두기** — 최종 결론을 스포하지 말고 궁금증 유발로 마감

**금지**:
- 원본에 없는 사실 창작 (허구는 형식이지 내용이 아님)
- 감정 과잉 · 진부한 광고 카피
- "~한 것으로 나타났다" 같은 리포트 문체 (그럴 거면 이 커맨드 쓸 필요 없음)

### 4. 콜아웃 박스 형식

원본 파일 최상단에 다음 형식으로 삽입:

```markdown
> [!STORY] 소설로 다시 읽는 이 보고서
> 
> <문단 1>
> 
> <문단 2>
> 
> <문단 3>
> 
> ...
>
> — *pxd-story · <YYYY-MM-DD>*

---

<원본 내용 그대로>
```

`[!STORY]` 는 GitHub 스타일 admonition. 지원 안 되는 렌더러에서도 인용문으로 자연스럽게 보임.

### 5. 복제본 저장

- **파일명**: `<원본_stem>_story<확장자>` (예: `final_report.md` → `final_report_story.md`)
- **위치**: 원본과 같은 폴더
- **이미 존재 시**: 사용자에게 덮어쓸지 물음

## 보고 형식

저장 완료 후:

```
✓ 소설풍 재구성 완료
- 원본: <원본 파일>
- 복제본: <_story 파일>
- 콜아웃 문단 수: N개
- 원본 대비 추가된 라인 수: M

미리보기 (콜아웃 첫 문단):
> <첫 문단 요약 1~2줄>
```

## 특이 케이스

- **인자 비어있음**: "보고서 파일 경로를 알려주세요. 예: `/pxd-story analysis/final_report.md`"
- **파일 없음**: 위 2번 안내
- **파일이 너무 짧음** (< 500자): 소설로 재구성할 재료가 부족함을 알리고 저장 여부 물음
- **바이너리 파일** (pdf 등): "PDF 는 아직 지원 안 됨. `.md`, `.html`, `.txt` 만 처리 가능" 안내
- **원본에 이미 `[!STORY]` 콜아웃 있음**: 이미 재구성됐다고 알리고 덮어쓸지 물음

## 예시

입력: `/pxd-story report/final_report.md`

콜아웃 본문 예시 (아누아 US 선케어 프로젝트 기준):

> [!STORY] 소설로 다시 읽는 이 보고서
> 
> 뉴욕 브루클린의 한 아파트, 30대 초반의 아시아계 여성 P12 는 세면대 앞에서 두 개의 튜브를 번갈아 든다. 하나는 3년째 쓰던 미국 대형 브랜드, 다른 하나는 어제 친구가 준 한국 브랜드의 샘플이다. 발라본다. 처음엔 반신반의, 두 번째 손등엔 조심스러운 기대.
> 
> 오후 세 시, 그녀는 사무실 화장실 거울 앞에서 두 손등을 다시 비교한다. 왼쪽은 조금 붉게 올라와 있고, 오른쪽은 여전히 매끈하다. 그녀는 SNS 앱을 연다. 검색창에 그 낯선 한국 브랜드 이름을 친다. 10만 개의 리뷰. 15,000 개의 좋아요. 그리고 하나의 문장이 눈에 들어온다. "발효 성분이 진짜 다르더라구요."
> 
> 이 보고서는 그런 순간들을 50번 모은 기록이다. 광고가 아닌 손등에서 시작된 결정, 캠페인이 아닌 텍스트 5줄에서 굳어진 신뢰. N=50 의 미국 소비자들이 어떻게 브랜드를 발견하고, 시험하고, 결국 지갑을 여는지에 대한 이야기.
> 
> 그리고 그 이야기의 결말에서, 우리는 아누아가 지금 이 시장에서 어디에 서 있는지 확인하게 된다.
