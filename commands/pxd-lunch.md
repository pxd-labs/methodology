# pxd-lunch — 팀원 좋아하는 음식 기반 점심 메뉴 참고

`~/pxd-responses/` 에 저장된 팀원 온보딩 응답을 읽어서 좋아하는 음식을 정리하고, 오늘의 점심 메뉴 추천을 뽑아줍니다.

## 실행 단계

### 1. 최신 응답 sync (자동 pull)

먼저 원격 저장소의 최신 상태를 가져옵니다:

```bash
cd ~/pxd-onboarding-responses
git pull --ff-only 2>&1
```

pull 이 실패해도 계속 진행 (로컬 데이터로 표시하되 사용자에게 경고).

### 2. 응답 파일 읽기

`~/pxd-responses/*.md` 파일 중 `README.md` 를 제외한 모든 파일을 읽어서 각 파일에서 다음 두 필드만 추출:

- **이름**
- **좋아하는 음식**

### 3. 결과 출력 형식

```
🍽  pxd 팀 점심 메뉴 참고 · 총 N명

팀원별 좋아하는 음식:
- <이름1> → <음식1>
- <이름2> → <음식2>
- ...

💡 오늘의 추천 (랜덤 pick): <음식>
```

랜덤 pick 은 위 리스트에서 하나를 균등확률로 뽑기.

### 4. 부가 정보

응답이 5명 이상이면, 음식 카테고리 요약도 함께 표시:

```
📊 카테고리 요약:
- 한식: 3명
- 양식: 2명
- 일식: 1명
- 기타: N명
```

카테고리 분류는 상식선에서 판단 (김치찌개=한식, 파스타=양식, 돈까스=일식 등).

## 특이 케이스

- **응답 파일이 하나도 없을 때**: "아직 등록된 팀원이 없습니다. `/pxd` 로 온보딩부터 진행하세요."
- **pull 실패 (네트워크·인증 문제)**: 로컬 파일만 읽고, 상단에 `⚠ 최신 sync 실패 — 표시된 데이터가 오래됐을 수 있음` 경고.
- **응답 파일 파싱 실패**: 해당 파일은 건너뛰고 마지막에 어떤 파일이 파싱 실패했는지 알림.
