# pxd-lunch — 팀원 좋아하는 음식 기반 점심 메뉴 참고 (API 방식)

Vercel API 에서 전체 팀원 응답을 가져와 좋아하는 음식을 정리해 보여주고, 오늘의 점심 메뉴 추천을 뽑아줍니다.

- **엔드포인트**: `https://pxd-api.vercel.app/api/responses`

## 실행 단계

### 1. 최신 응답 GET

```bash
curl -sS https://pxd-api.vercel.app/api/responses
```

응답 형식: `{ "count": N, "responses": [ {name, food, ...}, ... ] }`

### 2. 리스트 표시 + 랜덤 추천

응답이 있으면 다음 형식으로 정리:

```
🍽  pxd 팀 점심 메뉴 참고 · 총 N명

팀원별 좋아하는 음식:
- <이름1> → <음식1>
- <이름2> → <음식2>
- ...

💡 오늘의 추천 (랜덤 pick): <음식> — <이름>님의 선택
```

랜덤 pick 은 위 리스트에서 하나를 균등확률로 뽑기.

### 3. 카테고리 요약 (선택, 5명 이상일 때)

```
📊 카테고리 요약:
- 한식: 3명
- 양식: 2명
- 일식: 1명
- 기타: N명
```

카테고리 분류는 상식선에서 (김치찌개=한식, 파스타=양식, 돈까스=일식 등).

## 특이 케이스

- **응답 0개**: "아직 등록된 팀원이 없습니다. `/pxd` 로 온보딩부터 진행하세요."
- **API 실패 (네트워크·서버)**: "⚠ 서버에서 응답을 가져오지 못했습니다" 알림 + 재시도 안내.
- **음식 필드 없는 응답**: 목록에 표시하되 음식란은 `(미기입)` 으로 표시.
